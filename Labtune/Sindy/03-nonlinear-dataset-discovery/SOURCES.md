# Evidence sources and boundaries

The coordinator retrieved small official metadata pages/API responses before the lab run and supplied a digest. Agents did not browse these sources independently. No raw dataset, third-party loader or research implementation is redistributed.

1. **Silverbox:** https://www.nonlinearbenchmark.org/benchmarks/silverbox — official description: electronic Duffing-like system, second-order LTI dynamics with third-degree polynomial static feedback; V1 input, V2 measured output. Citation: T. Wigren and J. Schoukens, Three free data sets for development and benchmarking in nonlinear system identification, ECC 2013, DOI https://doi.org/10.23919/ECC.2013.6669201. Free availability is not treated as a verified redistribution license or proof of fault labels.
2. **UCI hydraulic condition monitoring:** https://archive.ics.uci.edu/api/dataset?id=447 and https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems — dataset DOI https://doi.org/10.24432/C5CW21. Metadata describe 2,205 instances, repeated 60-second hydraulic test-rig cycles and four superimposed component-condition types with severity grades. The supplied digest did not close all label, acquisition, grouping and licensing questions.
3. **Additional Tennessee Eastman Process Simulation Data for Anomaly Detection Evaluation:** https://doi.org/10.7910/DVN/6C3JR1 — official metadata endpoint https://dataverse.harvard.edu/api/datasets/:persistentId/?persistentId=doi:10.7910/DVN/6C3JR1. The checked metadata contain a public-domain dedication with disclaimer/no-endorsement language. This is the additional simulation-data release, not an arbitrary interchangeable TE benchmark split. Verify full current terms and file definitions before use.
4. **Cascaded Tanks:** https://www.nonlinearbenchmark.org/benchmarks/cascaded-tanks — pump-driven two-tank system with soft/hard overflow nonlinearities; dataset DOI https://doi.org/10.4121/12960104. Citation: M. Schoukens and J.P. Noël, Three Benchmarks Addressing Open Challenges in Nonlinear System Identification, IFAC 2017, DOI https://doi.org/10.1016/j.ifacol.2017.08.071. Which states are measured and applicable dataset terms still need checking.

These references support the stated descriptions, not every proposed experimental detail. Dataset licenses are separate from Labtune's software/documentation license. No source endorses this workflow or its recommendations.
